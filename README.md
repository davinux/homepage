# Homepage

A lightweight, self-contained bookmark manager that runs entirely in the browser. No server required — all data is stored in localStorage.

## Features

- **Categories & Bookmarks** — Organize links into named categories with drag-and-drop reordering
- **Multi-language** — English, French, German, Japanese, Chinese, and Spanish
- **Themes** — System, Light, Dark, Ocean, Forest, Sunset, and Midnight
- **Import / Export** — Export all bookmarks or individual categories as JSON, import from file
- **Responsive** — Works on desktop, tablet, and mobile with touch-friendly interactions
- **Edit Mode** — Toggle to add, edit, delete, and reorder categories and bookmarks
- **Welcome Screen** — Guided onboarding with sample bookmarks to get started quickly
- **Favicons** — Automatically fetches favicons for each bookmarked site
- **No Dependencies** — Single HTML file, no build step, no external libraries
